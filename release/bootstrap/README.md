# Intake site adapter registry bootstrap

`@tech-adventures-llc/intake-site-adapter@0.0.0-bootstrap.0` is an **unusable setup prerelease**. It contains no adapter code, API, executable, or working module entry. Do not install it in a site or depend on it for any runtime behavior.

Its sole intended purpose is a one-time, owner-approved registry setup step under the `bootstrap` dist-tag. The first usable public adapter version is `1.1.0`. Site repositories keep their existing exact pins until that release is independently verified.
